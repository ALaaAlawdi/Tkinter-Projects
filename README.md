# Tkinter-Projects
## Projects Overview

### 1. Simple Calculator
A basic calculator application that performs arithmetic operations like addition, subtraction, multiplication, and division. This project demonstrates the use of buttons, entry widgets, and grid layout.

### 2. To-Do List
A to-do list application that allows users to add, delete, and mark tasks as completed. This project showcases the use of listbox, scrollbars, and event handling.

### 3. Tic-Tac-Toe Game
A classic Tic-Tac-Toe game where two players can play against each other. This project highlights the use of canvas for drawing the game board and handling mouse click events.

### 4. Weather App
A weather application that fetches and displays weather information for a given city using an API. This project demonstrates the integration of Tkinter with external APIs and the use of labels and frames.

### 5. Text Editor
A simple text editor with basic functionalities like opening, saving, and editing text files. This project illustrates the use of text widgets, menus, and file dialogs.

Each project is contained in its own directory with a README file explaining the features and providing instructions on how to run the project.
